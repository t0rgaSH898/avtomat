# Линейно‑ограниченные автоматы 
  ## **Множество состояний Q**:
  ## Q = { q0, q1, q2, q3, q4, qaccept, qreject }
  ## q0 - начальное состояние;
  ## q1-q3 - рабочие состояния для проверки структуры строки;
  ## qaccept - состояние принятия;
  ## qreject - состояние отклонения.
  ## **Входной алфавит Σ**:
  ## Σ={a,b,c}
  ## **Алфавит ленты Γ**:
  ## Γ={a,b,c,X,Y,Z,⊔}
  ## X — маркер обработанных a;
  ## Y — маркер обработанных b;
  ## Z — маркер обработанных c;
  ## ⊔ — пустой символ (пробел).
  ## **Выходной алфавит не требуется**
  ## **Функция переходов δ**:Q×Γ→Q×Γ×{L,R}:
  ## Определяет, как автомат меняет состояние, записывает символ на ленту и перемещается (влево/вправо).
  ## **Начальное состояние**: q0.
  ## **Конечные состояния**:
  ## F = {qaccept} - строка принята;
  ## неявно qreject - строка отклонена.
